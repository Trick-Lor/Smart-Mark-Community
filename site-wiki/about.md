# About Smart Mark

Smart Mark lets you mark and highlight any element or area on a web page using keyboard shortcuts - outline elements, draw areas, and save layouts. Point with the mouse, act with the keys: no toolbar, no menus. No data collected; everything stays on your device.

## Privacy {#privacy}

Smart Mark has no server, no analytics and no tracking. Your settings and saved layouts live in Chrome's own storage; if Chrome sync is on, Chrome itself copies the settings between your signed-in browsers.

## Frequently asked questions {#faq}

### Is Smart Mark free?

Yes. Smart Mark is completely free, with no ads and no accounts.

### Does it collect my data?

No. Your settings and marker layouts are saved in Chrome's own storage. If Chrome sync is on, Google Chrome copies them between your signed-in browsers; Smart Mark has no server, sends nothing to the developer or any third party, and the extension contains no analytics or tracking.

### Which browser does it work on?

Google Chrome (Manifest V3). It runs on any normal web page, but not on chrome:// internal pages or the Web Store.

### Do I have to memorize shortcuts?

No. The popup lists every shortcut, a toast shows the active mode as you work, and you can change almost any combo on the Options page (the popup shortcut is changed at chrome://extensions/shortcuts, and Esc stays Esc).
