# Mark Selected Text

Select some text, right-click it, and mark exactly that text: as one box around it, or as a highlight band on each line, like a highlighter pen.

::: info
Available from Smart Mark 1.1.0. If your installed version is older, this feature arrives with the next Chrome Web Store update.
:::

![Mark Selected Text](/media/mark-text.gif)

## Before you start

- Smart Mark installed.
- A page with text you want to point out.

## Step by step

1. Select the text with the mouse.
2. Right-click it and open Smart Mark.
3. Pick Mark text: box (one marker around the selection) or Mark text: highlight lines (one band per line).
4. The text is marked, the selection is cleared, and a toast confirms it.

## With a shortcut

- Mark selected text has no key at first. Give it one in Options > `Keyboard Shortcuts`, for example `Alt + S`.
- The shortcut marks in the default style: Options > `Marker Configuration` > `Selected text` > `Default text style` (`Box` or `Highlight lines`).
- Once bound, the right-click item of the default style shows the key, for example Mark text: box (Alt+S).

## Tips

- A highlight is one marker however many lines it covers: one `Ctrl + Z` removes it, and a slot saves it whole.
- The box style uses your current shape, fit, offset, and `Marker` color. The highlight uses `Text highlight` (Options > `Colors & Style`), yellow by default.
- Text inside an input or a text area cannot be marked; select text on the page itself.

## Shortcuts used here

| Keys | Action |
| --- | --- |
| `Ctrl + Z` | undo the last mark, a whole highlight included |
| `Ctrl + Alt + ,` | open the Options page to bind the shortcut |

The combos above are the defaults; every one of them can be rebound on the Options page.
