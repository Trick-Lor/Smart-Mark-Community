# Save and Load Layouts

Save the markers on a page into a numbered slot, then restore them any time - up to 10 slots per page. Great for reusable review checklists or coming back to a page later.

![Save and Load Layouts](/media/save-and-load.gif)

## Before you start

- Place some markers on a page first.

## Step by step

1. Press `Ctrl + Shift + Alt + 0-9` to save the current markers to slot 0 through 9.
2. Reload or come back to the page later.
3. Press `Alt + 0-9` to load the markers back from that slot (it replaces the current markers).
4. The popup highlights which slots are occupied.

## Manage slots

- Options > Marker Slots: the x on a slot tile deletes that slot; Delete all slots wipes every slot after you confirm.
- Confirm overwrite: saving into a slot that already holds markers then needs a second press within 3 seconds; the first press only shows a toast.
- Slots shown (1-10) sets how many tiles the popup and Options show. Hidden slots keep their shortcuts and their data.

## When markers go away

- Markers you did not save disappear when you reload the page or leave it. Save to a slot first.
- Scrolling or a change on the page does not move or delete a marker; only Clear, undo, or a reload removes it.
- A slot loads on any page. If it was saved on another page, a toast names that page.

## Tips

- Numpad number keys also work for the slot shortcuts.
- Slots live in Chrome's own storage. With Chrome sync on, Chrome copies them to your other signed-in browsers; Smart Mark itself sends them nowhere.

## Shortcuts used here

| Keys | Action |
| --- | --- |
| `Ctrl + Shift + Alt + 0-9` | save current markers to slot N |
| `Alt + 0-9` | load markers from slot N (replaces current) |

The combos above are the defaults; every one of them can be rebound on the Options page.
