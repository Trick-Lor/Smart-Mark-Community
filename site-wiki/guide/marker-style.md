# Marker Style

Decide how markers look and behave: line width, solid, dashed or dotted lines, fill opacity, how dark the overlay gets, how long a toast stays, and how many steps undo remembers. Every change applies live.

::: info
Available from Smart Mark 1.1.0. If your installed version is older, this feature arrives with the next Chrome Web Store update.
:::

![Marker Style](/media/marker-style.gif)

## Before you start

- Open the Options page (`Ctrl + Alt + ,`).

## Step by step

1. Open the Options page and expand Colors & Style. The live preview redraws with every change.
2. Marker: line width (1-10 px), line style (solid, dashed, dotted), and fill opacity (0% keeps the classic outline-only look).
3. Preview: width and fill of the outline you see while hovering or drawing, plus overlay dim opacity (0-60%).
4. Toast duration (0.5-5 s) is under Notifications; undo depth (10-500 steps) is under Marker Configuration.
5. Reset colors & style returns these values to the selected profile.

## Highlighter look

- Open Profiles and apply the Highlighter preset: a 35% yellow fill with a thin line, like a highlighter pen.

## Tips

- Hover any option row: a note explains it and the live preview points at the part it changes.
- Colors and style combine: the color picker sets the hue, the style rows set the opacity.
