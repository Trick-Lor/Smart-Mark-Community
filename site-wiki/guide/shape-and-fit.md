# Shape and Fit

Change the marker shape (Rectangle, Oval, Diamond) and how tightly it fits its target, on the fly with the keyboard. The change applies to the markers you draw next, in any marking mode.

_Video coming soon._

## Before you start

- Install Smart Mark and pin its icon.
- Be in any marking mode (Element, Free Draw, or Merge).

## Step by step

1. Press `Alt + O` to cycle the shape: Rectangle, Oval, Diamond.
2. Press `Alt + W` to cycle the fit: Inscribe (inside the box), Median (middle), Circumscribe (around the box).
3. Press `Alt + =` or `Alt + -` to grow or shrink the box by 5 px; hold `Ctrl` too for 1 px steps.
4. Press `Alt + ]` or `Alt + [` to round the corners 1 px more or less (Rectangle and Diamond only).
5. Draw a marker - it uses the current shape, fit, offset, and corner radius.
6. Options > Marker Configuration holds the same values plus Base offset, a fixed number of pixels added to every marker on top of the offset.

## Tips

- A toast shows the current shape and fit each time you press the key, so you always know the active setting.
- Oval and Diamond are great for circling or pointing at round or irregular targets.

## Shortcuts used here

| Keys | Action |
| --- | --- |
| `Alt + O` | cycle shape: Rectangle, Oval, Diamond |
| `Alt + W` | cycle fit: Inscribe, Median, Circumscribe |
| `Alt + =` | offset +5 px (coarse) |
| `Alt + -` | offset -5 px (coarse) |
| `Ctrl + Alt + =` | offset +1 px (fine) |
| `Ctrl + Alt + -` | offset -1 px (fine) |
| `Alt + ]` | corner radius +1 px |
| `Alt + [` | corner radius -1 px |

The combos above are the defaults; every one of them can be rebound on the Options page.
