# Free Draw

Draw a rectangular marker anywhere on the page, not tied to any element. Drag it out freely, or click two opposite corners for precision.

<!-- media: free-draw -->

## Before you start

- Install Smart Mark and pin its icon.
- Open any normal web page.

## Step by step

1. Press `Alt + X` to turn on Free Draw mode.
2. Click and drag on the page to draw a rectangle, then release to place the marker.
3. Optional: press `Shift + X` to switch to two-click mode - click one corner, then the opposite corner.
4. Repeat to draw more markers.
5. Press `Esc` to exit when you are done.

## Shape the marker (optional)

- `Alt + O` - change the shape: Rectangle, Oval, or Diamond.
- `Alt + W` - change the fit: Inscribe, Median, or Circumscribe.
- `Alt + =` / `Alt + -` - grow or shrink the box by 5 px.
- Open the Options page to set the Free draw color.

## Undo and clean up

- `Ctrl + Z` undo the last marker, `Ctrl + Y` redo.
- `Ctrl + Shift + X`, then click a marker to remove just that one.
- `Ctrl + Shift + Alt + X` remove all free-draw markers at once.

## Save your work

- `Ctrl + Shift + Alt + 0-9` save the current markers to slot 0-9.
- `Alt + 0-9` load the markers back from a slot.

## Tips

- While dragging, a blue outline shows the raw box from your start point, so you can place it precisely.
- Two-click mode is handy when a clean drag is hard (for example across scrolling content).

## Shortcuts used here

| Keys | Action |
| --- | --- |
| `Alt + X` | turn on Free Draw mode (drag to draw) |
| `Shift + X` | switch to two-click corner mode |
| `Ctrl + Shift + X` | click to remove free-draw markers |
| `Ctrl + Shift + Alt + X` | remove all free-draw markers |
| `Esc` | exit the mode |

The combos above are the defaults; every one of them can be rebound on the Options page.
