# Settings Search

Find any setting, section, or shortcut by typing a word or a key combo. It works in both the popup and the Options page, and it only filters and jumps - it never runs an action.

::: info
Available from Smart Mark 1.1.0. If your installed version is older, this feature arrives with the next Chrome Web Store update.
:::

_Video coming soon._

## Before you start

- Open the popup (`Ctrl + ,`) or the Options page (`Ctrl + Alt + ,`).

## Step by step

1. The search box sits under the header. On the Options page, press `/` to jump into it.
2. Type a word such as `color` or `toast`. Sections without a match hide; matching sections open with a hit count and the matched text is highlighted.
3. Type a key combo such as `alt+i` (or `alt i`) to find the shortcut bound to those keys. After you rebind a shortcut, search finds the new keys.
4. Press `Esc` or the x button to clear. Every section returns to the open or closed state it had before.

## In the popup

- Results that only exist on the Options page are listed under In Options.
- Click one to open the Options page scrolled to that setting, with the setting flashing.

## Tips

- Vietnamese words match with or without diacritics.

## Shortcuts used here

| Keys | Action |
| --- | --- |
| `Ctrl + ,` | open the popup |
| `Ctrl + Alt + ,` | open the Options page |

The combos above are the defaults; every one of them can be rebound on the Options page.
