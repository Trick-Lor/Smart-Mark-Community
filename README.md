# Smart Mark

Mark web page elements and areas using keyboard shortcuts. No toolbar, no menus -- just shortcuts.

[Install from Chrome Web Store](#) <!-- link updated once published -->

---

## How it works

Smart Mark overlays a color marker on any element or area you choose. All actions are keyboard-driven; nothing requires clicking a button or opening a menu.

Three marking modes:

- Element mode (`Alt + Z`) -- hover over any HTML element and press `Shift + Z` to mark it.
- Free draw mode (`Alt + X`) -- drag to draw a marker rectangle anywhere on the page.
- Merge mode (`Alt + Q`) -- click two elements to mark the area spanning between them.

Other shortcuts:

- `Ctrl + Z` / `Ctrl + Y` -- undo / redo the last marker action
- `Ctrl + Shift + D` -- remove a single marker (click to target it)
- `Ctrl + Shift + Alt + D` -- clear all markers on the page
- `Alt + 0-9` -- load a saved marker layout from slot N
- `Ctrl + Shift + Alt + 0-9` -- save the current markers to slot N
- `Ctrl + ,` -- open the popup (rebind under `chrome://extensions/shortcuts` if it conflicts)

All shortcuts are customizable from the extension options page (`Ctrl + Alt + ,`).
