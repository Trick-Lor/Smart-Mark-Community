# Smart Mark

A Chrome extension that lets you place markers on any web page using keyboard shortcuts. No mouse menus, no clicks -- just shortcuts.

## What it does

- Mark any HTML element by hovering over it
- Draw a free marker anywhere on the page
- Merge two elements into one marker area
- Undo / redo markers
- Save and load marker layouts to numbered slots (0-9)

## Quick start

1. Open `chrome://extensions`, enable Developer mode
2. Click "Load unpacked" and select this project folder
3. Go to any web page and use the shortcuts
